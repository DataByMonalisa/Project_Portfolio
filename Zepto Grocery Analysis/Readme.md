# 📊 Inventory Analysis using SQL
## Welcome to my first end-to-end SQL project!
In this project, I performed an inventory analysis on a retail dataset to validate stock data, check pricing and discounts, and extract actionable insights to support business decisions.

# 🔍 Project Overview
## Objective:
To practice SQL for real-world business analysis by exploring an inventory dataset and answering key operational questions.

## Dataset Highlights:

Product categories, MRP, discount percentage, selling price, available stock, and weight.

Includes fields to identify out-of-stock or low-stock products.

# Tools Used:

SQL (queries run in VS Code)

Spreadsheet/PDF for presentation

AI assistant for step-by-step learning guidance

# 📂 Project Files
## File	Description

# 🗂️ Key Steps in Analysis
## Data Validation

- Checked for nulls and inconsistencies.

- Verified pricing vs. discount formulas.

- Inventory Health Check

- Total unique products.

- Total stock units.

- Total potential revenue (MRP vs. discounted price).

## Category Performance

- Stock and revenue by category.

- Average discount per category.

- Risk Identification

- Out-of-stock items.

- Low-stock items (threshold: < 5 units).

# Key Findings & Recommendations

### See below for summary.

## ✅ Key Findings
- Inventory is healthy overall with well-maintained stock levels.

- High-revenue products are clearly identified and should be prioritized.

- A few products are critically low or out of stock and need immediate restocking.

# 📝 Recommendations
- Restock critical and high-demand items promptly to prevent lost sales.

- Monitor top revenue items closely to maintain availability.

- Review discounts regularly to ensure they align with profitability goals.

- Perform periodic data audits for consistent inventory health.
